# 016 — INT 10h video BIOS

- **Status:** done
- **Milestone:** M1
- **Depends on:** 010, 015
- **Owner:** worker-1

## Goal
Video BIOS services for text output and mode switching.

## Scope (`bios/video.rs`)
- AH=00 set mode (00–03, 07 text; dispatch table so 026/027 add 13h, 0Dh,
  12h, 04–06 register sets), 01 cursor shape, 02/03 cursor pos, 05 page,
  06/07 scroll, 08 read char/attr, 09/0A write char, 0E teletype (BEL, BS,
  CR, LF, scroll), 0F get mode, 10h palette/DAC subfunctions, 11h font info
  (1130h) and 8x8/8x16 load basics, 12h BL=10h EGA info, 1Ah display combo
  (VGA color), 1Bh minimal.
- Update BDA video fields; programs read them directly.
- Public Rust fn `teletype(bus, ch, page, attr)` for DOS CON (020).

## Acceptance criteria
- [x] Tests with a real VGA device on `Hardware`: mode 3 clears screen,
      teletype wrap + scroll, scroll window, cursor in BDA and CRTC.

## Review follow-ups
- [x] Point INT 1Fh (upper 8x8 chars) and INT 43h (graphics font) at the ROM
      font tables, and INT 1Dh at a video parameter table. They currently
      point at the dummy IRET.

## Notes
- Modes 00–03, 07 and 13h (registers incl. misc bit 0 for 3Bx/3Dx, DAC,
  BDA, memory clear) via `mode_params`; 026/027 add graphics register sets
  and the graphics paths of scroll / write char / teletype.
- No 8x14 font: 8x14 requests load the 8x16 font. Cursor emulation scales
  CGA shapes to the character height.
