# 007 — Complete 8086 instruction set

- **Status:** done
- **Milestone:** M1
- **Depends on:** 001, 002
- **Owner:** worker-1

## Goal
Every documented 8086/8088 instruction executes correctly.

## Scope
- Wire ALU ops: `00–3F` groups, `80–83`, `84/85` TEST, `F6/F7` (TEST NOT
  NEG MUL IMUL DIV IDIV; divide error → INT 0), `D0–D3`, `FE/FF` (INC DEC
  CALL JMP PUSH; keep `FE 38` callback), INC/DEC reg.
- String ops MOVS CMPS SCAS LODS STOS with REP/REPE/REPNE (each iteration
  costs a cycle; interruptible: re-run with IP at prefix when budget ends).
- IN/OUT (imm and DX, 8/16), XLAT, CBW/CWD, DAA/DAS/AAA/AAS/AAM/AAD, WAIT,
  ESC (D8–DF: decode ModRM and ignore — no FPU), SALC.
- 8086 quirks where cheap (POP CS ignored → treat 0F per 186+ later).

## Acceptance criteria
- [x] Tests for each opcode group on `FlatBus`; REP with CX=0; REP across
      segment wrap; DIV by zero vectors to INT 0 with correct return IP.
- [x] Small integration test: a hand-assembled loop computing a checksum.

## Notes
- REP runs one iteration per `step` (IP rewound to the prefix while
  iterations remain). #DE pushes the faulting instruction's IP (286+).
  Shift counts are masked to 5 bits (186+, from `alu.rs`). 8086 `60–6F`
  Jcc aliases and `C0/C1/C8/C9` are left to 025's 186 opcodes.
